# Python Data Analysis Curriculum

Responsive HTML/CSS/JavaScript curriculum portal.

Features:
- 21 modules
- Module navigation
- Foundation / Data Analysis / Professional filtering
- Module detail modal
- Practical work for every module
- Responsive desktop/tablet/mobile design
- Dark mode

Removed intentionally:
- Completion tracking
- Progress bar
- Progress percentage
- Complete buttons
- Reset progress
- localStorage progress data

Run by opening `index.html` in a browser.
